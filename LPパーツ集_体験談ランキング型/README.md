# LPパーツ集（体験談ランキング型）

「◯◯はやばい？使った感想＆実際に◯◯できた5選」型の記事LPを組むための部品集（25パーツ）。
参考サイトの**見せ方の型だけ**を抜き出して作り直したもので、参考サイトの文章・画像・サービス名は使っていない。

| ファイル | 中身 |
|---|---|
| `index.html` | パーツ集のページ。ブラウザで開くと、各パーツの「使う場面・ルール・NG・見本・コピーできるHTML」が見られる |
| `parts.css` | 部品のCSS（`mt-*`）。LPではこれを読み込み、本文を `class="mt-body"` で囲む |
| `build.cjs` | `index.html` と `parts.css` を作り直すスクリプト（`node build.cjs`） |

## 使い方

1. `parts.css` をLPのフォルダにコピーして読み込む（またはLPの `style.css` に中身を足す）。
2. `index.html` を開き、使うパーツの「HTMLを見る・コピー」から貼り付ける。
3. 仮の文言（サービスA など）とダミー画像を差し替える。

## 基本ルール（index.html 冒頭と同じ）

- 流れ：タイトル → アイキャッチ → 悩みの問いかけ → 共感 → 答えの予告 → PR・年齢注記 → 比較表 → 結論ボックス → 口コミ（良い・悪い）→ 自分の体験 → ランキング → 1位の深掘り → まとめ → 全順位のボタン → 関連記事
- 色：青＝見出し・ボタン／赤＝強調・注意／黄マーカー＝結論
- ボタン：大ボタンの上に「＼ひとこと／」、下に注記。ボタンには光が走るアニメーション（動きを減らす設定の人には出ない）
- 必ず入れる：冒頭のPR表記・年齢などの注記・口コミや体験談の「※個人の感想です」。体験していないことは書かない
