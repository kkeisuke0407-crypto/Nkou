# Stage12｜体験談パーツ使用ルール

更新日: 2026-09-27

基本デザインシステム：`LPパーツ集_体験談ランキング型/`（parts.css の `mt-*`）。
「参考にする」ではなく、**原則として既存の mt-* パーツを組み合わせてLPを作る**。

## 記事LPのリズム

見出し → 文章 → 画像 → 比較表 → 結論 → 体験談 → ランキング → 詳細訴求 → CTA

情報を何でも角丸カードに入れない。文章・写真・表・結論ボックスの順で読ませる。

## 表現ごとに使うパーツ

| 表現 | パーツ | メモ |
|---|---|---|
| セクションの見出し | `mt-h2` | 1セクションに1つ |
| 順位見出し・小分け | `mt-h3`（順位は `mt-h3__rank`） | 「1位」「2位」「3位」。メダル絵文字・金銀銅は使わない |
| 順位の中の話題 | `mt-h4` | 強調する語は1つだけ `<em>`（赤＋マーカー） |
| 比較 | `mt-hint`（上下）＋`mt-scroll`＋`mt-table` | パーツ集どおり：行＝学校、列＝比較ポイント、左列（学校名 `mt-name`）固定、推す行（N高）に `is-pick`、N高の行だけ `mt-mini-btn`。独自の c1-table 調整は使わない。星・点数・バッジは使わない |
| 結論・答え | `mt-conclusion`（`mt-conclusion__ttl`＝【結論】【答え】） | 比較表の直後／検索疑問への即答 |
| 特徴・重要ポイント | `mt-points` | 3〜5項目。事実を並べる（感想は本文へ）。番号つきは `c1-points--num` |
| 一言結論・短い強調 | `mt-oneline`（span が黄マーカー）、`mt-mark` | 1セクションに2か所まで |
| 生徒の声・体験 | 写真＋`mt-story` | 公式に載っている声の要約だけ。出典・「個人の感想です」を必ず添える |
| 手順・チェック項目 | `mt-steps` | 5項目まで |
| ランキングの画像 | `mt-banner`（N高は右上に PR） | 競合校は公式画像を使わない（CC BY-SA の写真＋クレジット） |
| 写真3枚 | `mt-photos` | 課外活動など |
| ボタン | `mt-cta`（`mt-cta__micro` は「＼◯◯／」の形で毎回変える） | 各順位の最後と最終CTA |
| 大ボタンの合間のリンク | `mt-textlink` | 「▶◯◯」＋small の注記。N高の資料請求だけに使い、競合校の公式サイトへの誘導には使わない（出典は小さい注記で書く） |
| 注記 | `mt-small`／`c1-proof__src` | 出典は数字や主張のすぐ下に |
| 冒頭のPR表記 | `c1-pr`（`shared/partials/pr.html`） | 「PR｜広告を含みます」だけ。12.5px・濃いグレーで、PRと分かる状態に。ランキングの根拠・確認日はここに書かず、ランキング表の直後に「※順位は◯年◯月◯日時点の各校公式情報をもとに、当サイトが独自に整理しています。」と注記。A8・広告主の文言指定があればそちらを優先 |

## デザイン方針（2026-09-27 変更）

**デザインは体験談パーツに忠実、事実・広告ルールは正確。**

- N高ブランドガイドラインの「落ち着いた見せ方」「強調を抑える」といったデザイン上の制約よりも、体験談ランキング型パーツの視線誘導・強弱・記事LPらしさを優先する。
- ポートフォリオLPは `parts.css` をそのまま読み込み、`core01.css`（落ち着いた配色への上書き）は読み込まない。mt-* の色・装飾を地味な方向へ上書きしない。
- 強弱は「通常文 → 黄色マーカー（mt-mark） → 赤（mt-red／mt-h4 の em）」の3段階。1セクションで一番伝えたい1〜2カ所を強くする。全部は強調しない。
- 結論は mt-conclusion の【結論】【答え】【比較の結果】で見せる。CTAの上には「＼押す理由／」のマイクロコピー、下に mt-cta__note。
- 順位はパーツどおり「🥇第1位：学校名｜ひとこと」。比較表は行＝順位順で、左列に mt-badge の「1位／2位／3位」。1位N高は明確に強く（大きめのバナー・一言結論・テキストリンク・大ボタン）。
- 強調は増やしても、カードは増やさない（白い角丸カードの乱造・3カード横並びの繰り返しはしない）。

引き続き守ること：

- 事実と異なる内容を書かない。架空の口コミ・星評価・点数・疑似スコアを作らない。
- PR表記（冒頭「PR｜広告を含みます」）。順位の根拠と確認日はランキングの直後に注記。
- 条件の違う金額を横並びで安い順に比べない。数字・主張には出典。
- 2位・3位は公式情報の魅力を公平に書く（3位の理由も長所で書く）。競合校の公式サイトへの目立つ誘導は置かない（出典は小さい注記）。
- A8・広告主の必須レギュレーション、商標出稿などの案件固有ルールを優先する。

## 独自クラス（c1-*）を足してよい場面

既存パーツで表現できないN高固有の機能、画像のトリミング、計測、レイアウト調整だけ。
今回 `ポートフォリオLP/shared/portfolio.css` に足したもの：

| クラス | 理由 |
|---|---|
| `c1-logo-cell`・`c1-table-logo` | 比較表の学校名セル（順位バッジ・公式ロゴ・学校名）の最低幅。ロゴは元の比率のまま |
| 土台（`c1-wrap`・`c1-sitebar`・`c1-pr`・`c1-voice`・`c1-fee`・`c1-note__table`・`c1-figure`・`c1-docs`・`c1-sources`・`c1-sticky` など） | core01.css を読み込まなくなったため、本文幅・画像レイアウト・表・SP固定CTA（計測）の最低限だけを portfolio.css に移した。色は parts.css のトークンを使う |
| `c1-spec`・`c1-spec__note` | 各校の基本情報（mt-table を縦の項目表として使う）の列幅と、就学支援金注記の表示 |
| `c1-banner--square` | N高の公式バナー（正方形・文字入り）を mt-banner の中で切らずに表示 |
| `c1-school-photo`（`--daiichi`） | 競合校のCC写真を16:9に切り、看板・校名が入る位置に合わせる |
| `c1-credit` | CC BY-SA のクレジット表記の文字サイズ |
| `c1-course` | コース説明図（文字入り）を切らずに表示 |
| `portfolio-hero`（`__visual`・`__overlay`・`__text`・`__eyebrow`・`__title`・`__note`・`__lead`） | 全ポートフォリオ共通のFV（16:9背景画像＋HTML見出し）。FVだけ独自デザイン、本文は mt-* という役割分担 |
| `c1-img-schooling-wide` | CP04のスクーリング写真のトリミング |
| `c1-final-banner` | 最終CTAのバナー表示 |
| `c1-oneline--num` | mt-oneline の中の実数（進路決定率）を大きく見せる |

CORE01から引き継いで使っている c1-*：c1-table・c1-scroll（比較表の調整）、c1-voice（生徒の声の写真レイアウト）、c1-fee（学費表）、c1-note__table（変更ルール表）、c1-caution__imgs、c1-figure・c1-framed、c1-docs、c1-sticky（SP固定CTA・計測）、c1-pr・c1-sources。

使わなくしたCORE01の独自UI：FVの2枚分割写真（家で学ぶ日／通って学ぶ日）、FVの結論カード、共感の吹き出し、358校の数字ボックス、自分ごとチェック、時間軸、Q見出し（c1-ev）、出願期間ボックス、学校選びの流れチップ、最終CTAのグラデーション帯。いずれも mt-conclusion／mt-points／mt-steps／mt-h3 などに置き換えた。
