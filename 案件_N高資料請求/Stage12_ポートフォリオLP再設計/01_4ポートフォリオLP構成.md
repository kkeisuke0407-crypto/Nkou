# Stage12｜4ポートフォリオLP構成

更新日: 2026-09-27

## 設計変更の要点

| | 旧設計（Stage11・橋掛けLP） | 新設計（Stage12・ポートフォリオLP） |
|---|---|---|
| 作り方 | 検索意図別のFVだけ差し替え、CORE01本文の途中（#axes など）へつなぐ | **ポートフォリオごとにLPの骨格そのものを変える** |
| 骨格 | 全LPほぼ同じ（CORE01） | CP01＝比較→ランキング／CP02＝答え→比較→ランキング／CP04＝答え→N高単品 |

| 公開先 | /nkou/compare/ /nkou/fee/ /nkou/select/ | 確認用 /pf/cp01/ /pf/cp02-fee/ /pf/cp04-schooling/（切り替えは確認後） |

旧設計のファイル（`Stage11_橋掛けLP設計/`・`橋掛けLP/`）は、公開中のため削除せず残している。

## 4つのLP型

「4枚のLP」ではなく「4つのテンプレート」。KWを追加するときは、同じ型のフォルダをコピーして中身を差し替える。

### CP01 ジャンル王道型（ランキング）

対象KW：通信制高校 おすすめ／ランキング／人気ランキング／比較／どこがいい、ネット高校、オンライン高校

| # | セクション | 中身 | 主なパーツ |
|---|---|---|---|
| 1 | タイトル・FV | H1「N高・クラーク・第一学院、どこがいい？」＋家／通学の写真＋1文の導入。**前置きを入れずに比較表へ** | c1-fv（既存） |
| 2 | 3校比較表 | 5項目（普段の学び方／通うペース／入学後の通い方の変更／相談・サポート／オンライン学習）＋【結論】 | mt-scroll＋mt-table、mt-conclusion |
| 3 | ジャンル理解・学校選びのポイント | 358校、5つのポイント、**順位のつけ方**（当サイトが公式情報で整理した順位であること） | mt-points、mt-h4 |
| 4 | ランキングTOP3一覧 | 順位／学校／順位の理由 | mt-table（c1-rank） |
| 5 | 1位 N高グループ詳細 | バナー→一言結論→特徴→基本情報→コース→変更ルール→メンター→生徒の声→CTA | mt-h3、mt-banner、mt-oneline、mt-points、mt-table、mt-h4、mt-story、mt-cta |
| 6 | 2位 クラーク記念国際詳細 | 校舎写真→一言特徴→特徴→基本情報（学費含む）→公式情報から見える特徴→公式サイトへのテキストリンク | 同上（CTAは mt-textlink のみ） |
| 7 | 3位 第一学院詳細 | 2位と同じ構成 | 同上 |
| 8 | N高生の声 | 公式の生徒の声2件（1件目は1位詳細の中） | 写真＋mt-story |
| 9 | N高ってどんな高校生活？ | キャンパス105カ所・課外活動17,239名・進路決定率94.24％ | mt-h3、mt-photos、mt-oneline、mt-mark |
| 10 | 注意点 | 全員向けではない／スクーリング／学費表／地域差・卒業要件 | mt-h3、mt-h4、mt-oneline |
| 11 | 資料を見る理由 | 出願期間・学校選びの流れ・資料で見るところ | mt-points、mt-steps |
| 12 | 最終CTA | バナー＋ボタン＋テキストリンク | mt-h2、mt-cta、mt-textlink |

### CP02 その他ジャンル型（学費・口コミ・評判・パンフレット・資料請求など）

**検索ニーズへの答えを先に返す**。いきなり比較・ランキングへ行かない。

汎用の骨格：タイトル → FV → 検索ニーズを満たすコンテンツ → 比較表 → ランキングTOP3 → 1位詳細 → 2位詳細 → 3位詳細 → N高詳細（必要なら） → CTA

#### CP02 学費（実装済み：`CP02_その他ジャンル/fee/`）

| # | セクション | 中身 |
|---|---|---|
| 1 | タイトル・FV | H1「高校の学費、いくらかかる？ 答えは『通い方』で大きく変わります。」 |
| 2 | 学費検索への答え | 【答え】家中心なら年数万円台〜、週5日は年70万〜100万円ほど（就学支援金適用後の公式モデル。根拠の学校名・コース名を明記） |
| 3 | 学費のしくみ | ①授業料（単位ごと・支援金対象）②入学金・施設設備費 ③コース費用（支援金対象外）④その他（PC・交通費） |
| 4 | 具体例 | N高グループの初年度モデル表、7.3万円の内訳、3年間19.9万円、週1＋〜週5の考え方、CTA |
| 5 | 3校比較表 | 学費のしくみ／公式サイトの年額モデル／就学支援金／通うペース／入学後の変更。**条件が違う金額は安い順に並べない**と明記 |
| 6 | TOP3一覧 | 5項目＋「学費を公式サイトで具体的に確認できるか」で整理 |
| 7〜9 | 1位・2位・3位詳細 | CP01と同じ部品（各校の基本情報に学費行あり） |
| 10 | 資料請求 | 自分の場合の学費は資料で確認→出願期間→資料で見るところ→最終CTA |

#### CP02 口コミ・評判（未実装・型のみ）

検索ニーズ回答（「口コミを見るときの注意点」など） → 公式・確認できる声（N高公式の生徒の声、各校公式の生徒の声の要約） → 比較表 → ランキングTOP3 → 各校詳細 → CTA。
**口コミは創作しない**。掲載できるのは出典のある声だけ。

### CP03 競合KW型（設計のみ・実装しない）

`ポートフォリオLP/CP03_競合/DESIGN.md` を参照。競合名を表示しない現行ルールがあるため、3校ランキングは作らない。
FV → 比較すべきポイント → ジャンル理解 → N高の選択肢 → N高詳細 → 生徒の声 → CTA。
商標ルールが変更・確認できた場合だけ、CP01型の骨格（比較表＋ランキング）に切り替える。

### CP04 テール／インテント型（N高単品訴求）

対象KW：スクーリングとは／通信制高校 スクーリングとは／スクーリング 少ない／高校 オンライン授業／その他の具体疑問

**3校比較表・TOP3は入れない**。「スクーリングとは」で来た人に比較を読ませてから説明しない。

| # | セクション | 中身（`CP04_インテント/schooling/`） |
|---|---|---|
| 1 | タイトル・FV | H1「スクーリングとは？ 学校に行って、先生から直接受ける授業のことです。」 |
| 2 | 検索疑問への即答 | 【答え】スクーリング（面接指導）＝先生や他の生徒と対面で学ぶ授業。単位に必要（出典：文部科学省） |
| 3 | 詳しい説明 | 単位は3つでとる（レポート・スクーリング・試験）／何日くらい／どこで |
| 4 | 選ぶときの注意 | 日数・場所・泊まり・費用・ふだんの通い方との関係 |
| 5 | N高の場合 | 学年別の日数、沖縄伊計本校4泊5日、交通費・宿泊費は別、CTA |
| 6 | N高の詳細 | 1位詳細と同じ部品（順位なし） |
| 7 | 生徒の声 | 2件 |
| 8 | CTA | 最終CTA |

## 公開・切り替え

- 確認用URL（mainにマージ後）：https://nko.hakobu-family.com/pf/cp01/ ・ /pf/cp02-fee/ ・ /pf/cp04-schooling/（noindex）
- 広告の着地先を切り替えるときは、広告側の最終ページURLを /pf/... に変えるか、`.github/workflows/pages.yml` で /nkou/... の出力先を新LPに差し替える（どちらにするかは決めてから作業）。
- 計測：`lp_id` は pf_cp01_ranking／pf_cp02_fee／pf_cp04_schooling。CTA位置（cta_position）は rank1・life・fee_example・answer・nkou_detail・final・sticky など。
