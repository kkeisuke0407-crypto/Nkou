# Stage10｜4ポートフォリオ初期配信設計 V1

更新日: 2026-09-27

## 目的

CORE01を基本LPとして固定し、検索意図ごとに

**KW → 広告 → 橋掛け → CORE01 → N高資料請求**

を接続する。

KWP実測データ `nkou_kw_portfolio.csv` と、A8表示EPC **236.8円** を基準値として使用する。
A8 EPCは全体平均であり当サイトの確定値ではないため、採算判断の参考値として扱う。

## 4ポートフォリオ

| CP | ポートフォリオ | 初期役割 | 状態 |
|---|---|---|---|
| CP01 | ジャンル王道 | 比較・おすすめ・ランキング等 | 配信候補 |
| CP02 | その他ジャンル | 学費・費用・口コミ・スクーリング等 | 配信候補 |
| CP03 | 競合KW | 他校検討層をN高比較へ橋掛け | 条件確認後に配信 |
| CP04 | インテント（元データ: テール） | 選び方・スクーリング等の具体疑問 | 配信候補 |

## 重要な経済性

記事LP流入1クリックの参考価値は、

`A8 EPC 236.8円 × 記事LP→広告主遷移率`

で見る。

| 公式遷移率 | 参考LPクリック価値 |
|---:|---:|
| 10% | 23.7円 |
| 20% | 47.4円 |
| 30% | 71.0円 |
| 40% | 94.7円 |

よって、KWPの「ページ上部入札単価（低額帯）」が100〜200円の王道KWは、
そのまま相場どおりに買う前提では厳しい。

**初期方針は「相場より低い個別CPCで拾えるKWを探す」こと。**
A8 EPCは発生ベースの参考値なので、実測CVが入り次第、当サイト実績に置き換える。

### 初手で外す

「学校名だけでは違いが分かりにくい → まず通い方で3校を見る」
からCORE01へ接続。

「学費だけを見ると比較しにくい。コースで金額が大きく変わるので、通い方とセットで見る」

スクーリング系:
「ネット中心でもスクーリングはある。回数と通い方を先に比べる」
→ CORE01比較へ。

## CP03 競合KW

KWP上、最も経済性が良い可能性がある。

### 特に強い候補
- 第一学院高等学校 学費：月2,400 / 21円
- トライ式高等学院 学費：月2,400 / 35円
- クラーク記念国際高等学校 学費：月1,000 / 36円
- ヒューマンキャンパス高等学校 学費：月590 / 16円
- NHK学園高等学校 学費：月260 / 18円
- トライ式高等学院 口コミ：月590 / 30円
- 第一学院高等学校 口コミ：月320 / 17円
- クラーク記念国際高等学校 口コミ：月260 / 35円

A8 EPC 236.8円を参考にすると、
例: CPC21円なら記事→公式遷移率約8.9%で発生ベースの損益分岐参考値になる。
このため**低CPC競合ロングテールは最優先で検証する価値が高い。**

### ただし配信前の必須条件
1. A8の当該プログラムで、競合商標KWへの出稿可否を確認する。
2. 以前の運用ルールどおり、競合KW用の広告・LPでは競合名を表示しない。
3. 現在のCORE01は競合名を表示しているため、CP03へそのまま流さない。
4. CP03専用の競合名非表示版LPを作成してから開始する。

### 初手では純指名を避ける
「クラーク」「第一学院」等の学校名単体はボリュームは大きいがナビゲーション意図が強い。
最初は **学校名＋学費 / 口コミ / 費用 / コース** から。

### 初期候補
- 通信制高校 選び方：月210 / 141円
- スクーリングとは 高校：月260 / 97円
- 通信制高校 スクーリングとは：月110 / 82円
- 通信高校 スクーリングとは：月50 / 67円
- 通信制高校 スクーリング 少ない：月70 / 186円

### 初手で外す
- 進路の決め方 高校生：月170 / 4円
- 高校生 進路 決め方：月170 / 6円

CPCは非常に安いが、N高資料請求との距離が遠すぎるため初期データを汚す。

### 橋掛け
「高校選びで迷ったら、まず通い方・途中変更・スクーリングの3点を確認」
→ CORE01へ。

## 初期マッチタイプ

初期はデータの純度を優先する。

- ボリュームがある主要KW: **完全一致**
- 月10〜50程度の具体ロングテール: **フレーズ一致も併用可**
- インテントが広い単語の部分一致: 初期は使わない

※これはN高案件の初期テストルール。別案件の一致種ルールを流用しない。

## 初期入札

クリック最大化ではなく、低CPCで取れるゾーンを探す。

- CP01: 30〜50円から開始し、表示不足なら段階的に上げる
- CP02: 30〜50円
- CP03: 15〜30円（商標条件確認後）
- CP04: 25〜45円

KWP低額帯まで一気に上げない。
「表示が出る最低ライン」をAG/KW単位で探る。
