## 目的

CORE01を壊さず、検索意図ごとの「冒頭橋掛け」を作成してください。

最初に実装するのは以下3つです。

1. CP02 学費
2. CP01 王道
3. CP04 選び方

CP03競合KW版は別LPとして設計だけ行い、まだ既存CORE01へ直接接続しないでください。

## 実装ルール

- CORE01本文を複製して大きく改変しない
- 共通CSS/JSをできるだけ再利用
- 各LPで変更するのは主にtitle / description / FV / 導入 / 最初のCTA
- その後はCORE01共通本文へ自然につなぐ
- 現在のN高ブランドガイドライン対応を維持
- 「通信制高校」の表示上の多用を避ける
- ネガティブな生徒像を作らない
- 学費LPでは実質負担額に「※就学支援金の適用を受けた場合」を必ず表示
- ASP CTA URLはCORE01と同じ1カ所管理方式
- ASP URLに独自パラメータを追加しない
- CTA位置はdataLayer/GA4で計測
- スマホ375px最優先
- 既存画像を使用し、見切れ調整を維持
