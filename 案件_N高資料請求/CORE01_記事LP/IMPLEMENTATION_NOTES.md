## 5. 主な訴求とCTA設計

### 中心訴求
**「今の自分に合わせて選び、あとから学び方を変えやすい」**
- 証拠：4つの学び方＋公式FAQに明記された変更時期（3カ月／6カ月ごと）。
- 表現の制約：「いつでも自由に変えられる」「必ず変更できる」とは書かない。注意BOXで「いつでも好きなときに、ではない」「定員・選考・学費の変化あり」を同じ画面に置いた。

### CTA一覧（すべて同じ資料請求URLへ。`data-cta` で計測）

| data-cta | 位置 | 文言 | 直前の心理 |
|---|---|---|---|
| `fv` | FV | N高グループの資料を見てみる | 「結論だけ先に知りたい」人向け。上に「＼無料・入学を決めるものではありません／」 |
| `conclusion` | 結論＋証拠の直後 | N高グループの資料を見てみる | 証拠を見て「それなら」と思った瞬間 |
| `timeline` | 最大訴求の直後 | 自分の地域で選べるコースを確認する | 「自分の地域だとどうなる？」という疑問に答える形 |
| `check` | 自分ごとチェック（3個以上のときだけ表示） | 学費・コースを資料で確認する | 自分で条件を整理した直後 |
| `final` | 最終CTA | N高グループの資料を見てみる | 「今決めなくていい、比較材料として取る」 |
| `final-text` | 最終CTAの下 | 学費・コースを資料で確認する（テキストリンク） | ボタンを押しにくい人向けの低圧導線 |
| `sticky` | SP固定 | N高グループの資料を見る（無料）／コース・学費を確認 | 読み途中の取りこぼし防止 |

### 使わなかった表現
- 「今すぐ」「残りわずか」「今日だけ」などの限定・煽りは一切なし。
- 行動理由は「先延ばしするほど比べる時間が減る」「学費・コースは地域とコースで変わるので資料の方が早い」「違えば候補から外せばいい」の3つだけ。

## 8. 3つの壁への対応（セルフチェック）

### 壁1：読まない
- [x] **FVを3秒見て誰向けか分かるか** → H1が検索者の心の声（「毎日通うのはしんどそう。でも家だけも不安」）。ラベル「中学生・高校生向け｜通信制高校3校比較」と「N高グループ・クラーク記念国際・第一学院の3校を比べました」で、誰向け・何の記事かがFV内で分かる。
- [x] **「自分のことだ」と思えるか** → 2分割写真（家で学ぶ日／通って学ぶ日）＋「どっちか1つに、今決めなきゃダメ？」で迷いそのものを見せる。直下の共感ブロックに具体的な悩み5つ。
- [x] 一般論（「通信制高校を検討している方へ」）から始めていない。
- [x] 2〜3スクロールごとに、写真・比較カード・証拠カード・タイムライン・チェック・注意BOX・CTAのどれかが入る。段落は1〜2文。

### 壁2：信じない
- [x] 主張の直後に証拠がある：
  - 「違いが分からないのは当たり前」→ 358校（文科省）
  - 「通い方で比べる」→ 75.2％（Gakken調査、対象と人数つき）
  - 「候補に残ったのはN高」→ 証拠カード3枚（4つ／3カ月ごと／105カ所）＋キャンパス写真
  - 「あとから変えやすい」→ 変更時期の表（公式FAQ）
  - 「相談できる」「高校生活がある」「卒業後」→ 写真＋公式の数字（定義・時点・対象つき）
- [x] 「おすすめだからおすすめ」になっていない。順位は「5つの比較軸で整理した結果」と定義を明記。
- [x] 全員向けではないケースを3つ明記。
- [x] デメリット（スクーリング、学費差、地域差、卒業要件）を独立セクションで開示。
- [x] N/S/R高合計の数字は「3校の合計」「共用」と毎回書いた。数字の推測なし。
- [x] 体験談・口コミは創作していない（mt-story・mt-voiceは不使用）。

### 壁3：行動しない
- [x] CTA直前に「今資料を見る理由」セクションがある（地域・コースで学費が変わる／比較・相談には時間がかかる／違えば外せばいい）。
- [x] 「今ここでN高に決める必要はありません」と明言。CTAのマイクロコピーは「無料・入学を決めるものではありません」。
- [x] 嘘の限定性は使っていない。
