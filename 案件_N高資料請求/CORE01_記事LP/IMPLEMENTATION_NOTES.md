### 公開前に必ずやること
1. **`main.js` の `CTA_URL`（1カ所）にASP計測URLを貼る。** `data-cta` が付いた全リンク（8本）の `href` に、そのURLがそのまま設定されます（パラメータの追加などの加工はしない）。今は `#`。
2. `main.js` の `TRACKING_MODE` を計測環境に合わせる（GTMなら `"dataLayer"`、gtag.js直貼りなら `"gtag"`）。
3. サイト名は「高校えらびノート」（A8登録名と統一済み。`header` と `footer` の2カ所）。
4. 画像の利用許諾（「6. 画像の権利」）。

- **1〜3位の順位表示を削除。** 比較軸がN高の強みに寄って見えるため。「今回の比較で候補に残った」という表現だけ残し、クラーク・第一学院は「誰に合うか」で見せた。

- **自分ごとチェックを3校比較の直後へ移動。**
- **「今資料を見る理由」に出願期間（事実）と学校選びの流れを追加。** 煽りは使わず「焦って決める必要はない」と明記。
- **本文を約17％短縮**（表示テキスト6,527字 → 約5,400字）。結論と時間軸を1セクションに統合、重複していた証拠カード（4つ・3カ月ごと）を削除、コース・相談・進路の重複説明と注意点の長文を圧縮。
- **CTA計測を変更。** ASP URLにパラメータを足す実装をやめ、クリックイベントをdataLayer / gtagへ送る方式に。
- **画像のトリミングを画像ごとに調整**（「3. 使用画像一覧」）。

## 5. 主な訴求とCTA設計

### 中心訴求
**「今の自分に合わせて選び、あとから学び方を変えやすい」**
- 証拠：学び方をネット中心・週1＋・週3・週5の4パターンから考えられること＋公式FAQに明記された変更時期（3カ月／6カ月ごと）。
- 表現の制約：「いつでも自由に変えられる」「必ず変更できる」とは書かない。「4つのコース」とも書かない（公式のコースは3つ）。

### CTA一覧

| data-cta | 位置 | 文言 | 直前の心理 |
|---|---|---|---|
| `fv` | FV | N高グループの資料を見てみる | 結論だけ先に知りたい人向け。「＼無料・入学を決めるものではありません／」 |
| `check` | 自分ごとチェック（3個以上のときだけ表示） | 学費・コースを資料で確認する | 自分で条件を整理した直後 |
| `timeline` | 候補に残った理由の直後 | 自分の地域で選べるコースを資料で確認する | 「自分の地域だとどうなる？」 |
| `conclusion` | 証拠の直後 | N高グループの資料を見てみる | 証拠を見て「それなら」 |
| `final` | 最終CTA（ボタン＋テキストリンク。テキストは `data-cta-type="text"`） | N高グループの資料を見てみる／学費・コースを資料で確認する | 「今決めなくていい、比較材料として取る」 |
| `sticky` | SP固定 | N高グループの資料を見る（無料）／比べるための資料・入学は決まりません | 読み途中の取りこぼし防止 |

### 計測のしかた
- ASP計測URLは `main.js` の `CTA_URL` 1カ所で管理し、全CTAの `href` にそのまま設定する。JSはURLを改変しない。
- クリック時に `main.js` が次のイベントを送る（`TRACKING_MODE` で送り先を選ぶ）：
  - `dataLayer.push({ event: "cta_click", cta_position, cta_type, cta_text })`（GTM用。ASP URLの全文はAnalyticsに送らない）
  - または `gtag("event", "cta_click", {...})`（gtag.js直貼り用）
- `cta_position` は fv / conclusion / timeline / check / final / sticky。
- `CTA_URL` が `#` の間だけクリック時の画面ジャンプを止める。URLを入れたら通常どおり遷移する。

### 行動理由（嘘の限定性なし）
- 今ここでN高に決める必要はない（明言）。
- でも2027年4月入学なら、学校選びの時期はもう始まっている（第1期の出願期間という事実）。
- 資料 → 家族で相談 → 説明会 → 他校と比較 → 出願の判断、と意外と時間がかかる。
- だから「決める」ではなく「比較材料を先に持っておく」。違えば候補から外せばいい。
- 「急がないと入れない」「残りわずか」「今すぐ」は不使用。
